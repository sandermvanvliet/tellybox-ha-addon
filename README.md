# Tellybox add-ons for Home Assistant

[![Add repository to my Home Assistant][badge]][add]

Add-ons for [Home Assistant](https://www.home-assistant.io/) OS and Supervised installs.

## Tellybox

Parent-approved videos for young kids, cast to the TV through a Chromecast within a daily time allowance. See [Tellybox](https://github.com/sandermvanvliet/tellybox) and the [add-on documentation](tellybox/DOCS.md).

Install: click the badge above, or add `https://github.com/sandermvanvliet/tellybox-ha-addon` under **Settings > Add-ons > Add-on store > Repositories**.
